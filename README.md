## 🚀 Proyectos destacados

### 🏢 MasterServices — Sistema de Gestión Empresarial

Sistema integral de facturación, inventario, clientes y ventas para pequeñas y medianas empresas.

| Repositorio | Tecnologías | Estado |
|-------------|-------------|--------|
| [masterservices-api](https://github.com/Morelo-Dev/masterservices-api) | ASP.NET Core 8 · EF Core · SQL Server · JWT | ![GitHub](https://img.shields.io/github/last-commit/Morelo-Dev/masterservices-api?style=flat&label=último%20commit) |
| [masterservices-frontend](https://github.com/Morelo-Dev/masterservices-frontend) | React 18 · TypeScript · TanStack Query · Tailwind | ![GitHub](https://img.shields.io/github/last-commit/Morelo-Dev/masterservices-frontend?style=flat&label=último%20commit) |

**Funcionalidades:**
- Autenticación JWT con control de roles
- Gestión de clientes, proveedores e inventario
- Facturación electrónica con integración a API externa
- Reportes financieros exportables a PDF y Excel
- Auditoría completa de cambios del sistema
